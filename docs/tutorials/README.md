# Tutorials

[**Your first pipeline**](your-first-pipeline.md) — build a two-thread
pipeline in a fresh Cargo project: send values through a ring, fill it and
watch it push back, then run producer and consumer on separate threads and
shut down cleanly. Takes about ten minutes and assumes only a Rust
toolchain.

When you finish, the [how-to guides](../how-to/README.md) pick up where the
lesson stops.
